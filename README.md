# Saine's Clothing
This is the **Saine's Clothing** e-commerce platform built using the **MEAN stack** (MongoDB, Express, Angular, Node.js). 

## Features
- **Professional Branding**: Custom logos, hero sections, and "Saine's Clothing" identity.
- **Admin Panel**: High-fidelity dashboard for managing products and orders.
- **Cloud Integration**: Cloudinary for image storage and MongoDB Atlas for data.
- **Reactive Forms**: Robust validation and error handling.
- **Role-Based Access**: Secure routes for users and administrators.

## How to Run
- **Backend**: `npm run start` in the `backend/` directory.
- **Frontend**: `npm run start` in the `frontend/` directory.
